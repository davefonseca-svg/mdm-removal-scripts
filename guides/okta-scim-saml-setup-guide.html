Setting Up Okta SCIM + SAML with Iru Endpoint

One Okta app for user provisioning and sign in. Paste your tenant values once, and every step below fills itself in.
Confirmed via docs.iru.com · July 2026
The one thing to know: a single custom SAML 2.0 app in Okta can handle both SCIM provisioning and SAML sign in for Iru. The trap is order of operations: set up SCIM first and Okta forces placeholder URLs into the SAML fields, which break every login until replaced. This worksheet collects the real values first so placeholders are never needed. The Iru Endpoint app in the Okta Integration Network (OIN) cannot do SCIM; always build a custom app.

Iru console
SCIM: Account menu → Integrations → Discover integrations → SCIM protocol → Add and configure. Name it, click Generate token, copy the token right away (it is shown only once), and paste it into Value 1 above.
After setup: ellipsis → View Details → copy the SCIM API URL into Value 2 above. Either the api.iru.com or api.kandji.io form works.
SAML: Account menu → Access → Admin and authentication → + Authentication method. Name it, select SAML, click Create.
From Configuration information, copy the Service provider entity ID into Value 3 and the ACS URL into Value 4. Leave this Iru modal open; you return to it in Phase 4.

Select this connection under Require Authentication in the Automated Device Enrollment Library Item so device enrollment uses your new Okta sign in. For manual enrollments: Enrollment → Manual Enrollment → expand the Blueprint → Require Authentication.
5
Assign users and groups
Okta admin
Okta rule: the same group cannot sit on both Assignments and Push Groups. Assignments wins and the group may never push. Pattern that works: one assignment group (for example iru_endpoint_users) on Assignments, real org groups on Push Groups, and every pushed group member also in the assignment group.
Assignments tab → Assign → Assign to Groups: assign the assignment group.
Push Groups tab → Push Groups → Find groups by name: add each org group, select Create Group. These become available for Blueprint conditional logic in Iru.
Anyone enrolling a device must be assigned to this app. Unassigned users get an error at the Okta login prompt.
6
Verify
SCIM: assigned users appear under Users in Iru within minutes. Sync is one way and automatic (no Sync Now button); use Push Now on Push Groups to force a group update.
Enrollment: enroll a device with Require Authentication on this connection; confirm Okta login completes and the device lands in the right Blueprint.
